---
name: Template Route Zod Workaround
description: GetTemplateParams is not generated by Orval for the templates route
---

**Rule:** In `artifacts/api-server/src/routes/templates.ts`, use `const GetTemplateParams = DeleteTemplateParams` — do NOT import `GetTemplateParams` from `@workspace/api-zod`.

**Why:** Orval only generates param schemas for operations that have explicit request body schemas or responses with params. The GET /templates/:id endpoint has no request body, so Orval skips generating `GetTemplateParams`. `DeleteTemplateParams` has the identical shape `{ id: number }`.
